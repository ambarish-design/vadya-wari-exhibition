# Vādya Wāri

An original, responsive single-page website for Vādya Wāri, Baithak Foundation’s travelling encounter with Indian traditional instruments.

## Run locally

This project has no build step or third-party dependencies. From the project directory:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## What is included

- Original editorial direction and visual design
- Responsive layout and accessible navigation
- Interactive listening room: visitors choose an instrument, move across its form, and trigger a responsive digital sound study
- A contact form that opens the visitor’s email client; submissions are not stored by the website

## Before launch

Confirm the public contact address and replace it if needed. Replace the prototype’s synthesized sound studies with short recordings made or licensed specifically for Vādya Wāri. Add real session photography only once permissions and child-safeguarding consent are confirmed.
